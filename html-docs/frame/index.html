Frame Analysis

Linear-elastic 3D frame analysis by the direct stiffness method, with member loads, end releases, spring supports, force diagrams and design-demand envelopes that feed the RC capacity functions.

Overview

analyzeFrame takes nodes, members, supports and one load case, and returns displacements, reactions, member end forces and force diagrams. Section properties come from rectBeamToSectionProperties or are supplied directly, so the module itself does not depend on the RC code.

ℹ️ This is a first-principles structural analysis, not a code provision, so its exports carry a Matrix analysis badge. Only the stiffness modifiers in rectBeamToSectionProperties come from ACI 318-19.

Axes & conventions
TopicConvention
Global axesRight-handed X, Y, Z with Z up. DOFs: UX, UY, UZ, RX, RY, RZ.
Local axesETABS-style 1, 2, 3. Local 1 runs from the start node to the end node. DOFs: U1, U2, U3, R1, R2, R3.
Non-vertical memberLocal 3 = (1 × Z) normalised, horizontal; local 2 = 3 × 1, in the vertical plane pointing up. A member along +X has local 2 = +Z and local 3 = −Y.
Vertical memberLocal 2 = +X, local 3 = 1 × 2. A column along +Z has local 3 = +Y.
Member angleRotates local 2 and 3 about local 1 by the right-hand rule, in rad.
Section axesI33 is about local 3 and governs bending in the 1–2 plane (U2–R3, the major axis); I22 is about local 2 and governs the 1–3 plane (U3–R2). A rectangle with depth h along local 2: I33 = b·h³/12.
RotationsAll results use the right-hand rule. The reference stiffness matrix measures R2 and R3 the other way; analyzeFrame converts internally.
UnitsCoordinates, lengths and positions in mm; E, G in MPa; A in mm²; I, J in mm⁴; loads in kN, kN·m and kN/m; springs in kN/mm and kN·m/rad. Results in kN, kN·m, mm and rad.
Internal forcesForces and moments acting on the positive (+1) face of a cut, along the positive local axes. N is positive in tension; M3 is positive for sagging when local 2 points up; V2 = −dM3/dx.
ℹ️ Member loads in a global direction ("X", "Y", "Z") are per unit length of member, not per unit projected length.
Analysis flow
1
Validate the model (errors 301, 302, 303, 305, 306).
2
Member matrices: build the local stiffness, resolve member loads into local axes and fixed-end forces, condense end releases, and transform with T.
3
Assemble the global stiffness K (6 DOFs per node) and load vector F = nodal loads − fixed-end forces, then add spring stiffnesses.
4
Solve the free-DOF system by Cholesky factorisation; a singular matrix throws 304.
5
Recover reactions R = K·U − F, member end forces and force diagrams.
6
Check global force and moment equilibrium and report the residual in calculationDetails.

FN analyzeFrame(model, options?) Public API Matrix analysis

Analyses a 3D frame for one load case and returns displacements, reactions, member end forces and force diagrams.

Parameters
ParamTypeUnitRequired?Description
modelFrameModel—RequiredNodes, members, restraints and loads; see FrameModel
options.stationsnumber—OptionalEvenly spaced stations per member diagram (default 21); load breakpoints and zero-shear points are added
Example
TypeScript
const { sectionProperties } = rectBeamToSectionProperties({ fc_: 28, b: 300, h: 600 });

const result = analyzeFrame({
  nodes: [
    { id: "A", x: 0,     y: 0, z: 0 },  // mm
    { id: "B", x: 5000,  y: 0, z: 0 },
    { id: "C", x: 10000, y: 0, z: 0 },
  ],
  members: [
    { id: "AB", startNodeId: "A", endNodeId: "B", section: sectionProperties },
    { id: "BC", startNodeId: "B", endNodeId: "C", section: sectionProperties },
  ],
  restraints: [
    { nodeId: "A", ux: true, rx: true, uy: true, uz: true },
    { nodeId: "B", uy: true, uz: true },
    { nodeId: "C", uy: true, uz: true },
  ],
  memberLoads: [
    { type: "udl", memberId: "AB", direction: "Z", w: -40 },  // kN/m, downward
    { type: "udl", memberId: "BC", direction: "Z", w: -40 },
  ],
});
Returns
Result (excerpt)
{
  reactions: [
    { nodeId: "A", fz: 75,  /* kN */ … },
    { nodeId: "B", fz: 250, … },
    { nodeId: "C", fz: 75,  … },
  ],
  nodalDisplacements: [
    { nodeId: "A", ry: 0.0022161, /* rad */ … },
    …
  ],
  memberEndForces: [
    { memberId: "AB",
      start: { f2: 75,  m3: 0 },
      end:   { f2: 125, m3: -125 } },  // kN, kN·m
    …
  ],
  memberDiagrams: [
    { memberId: "AB",
      extremes: { M3: { max: { value: 70.3125, x: 1875 },
                            min: { value: -125,    x: 5000 } }, … },
      stations: [ { x: 0, V2: -75, M3: 0, … }, … ] },
  ],
  calculationDetails: { nodeCount: 3, memberCount: 2, dofCount: 18, freeDofCount: 10,
                         equilibriumResidual: { force: 0, moment: 0 } },
  units: { force: "kN", moment: "kN·m", length: "mm", rotation: "rad" },
  warnings: []
}

The results are the textbook two-span values: reactions 3wL/8, 10wL/8, 3wL/8, support moment wL²/8 = 125 kN·m and span moment 9wL²/128 = 70.3125 kN·m.

FieldTypeUnitDescription
nodalDisplacementsNodalDisplacement[]mm, radux, uy, uz, rx, ry, rz per node (global axes)
reactionsNodalReaction[]kN, kN·mfx…mz per node; zero at unrestrained DOFs. A spring DOF reports the force the spring exerts on the node
memberEndForcesMemberEndForces[]kN, kN·mf1, f2, f3, m1, m2, m3 that the node exerts on each member end, local axes, right-hand
memberDiagramsMemberDiagram[]kN, kN·m, mmN, V2, V3, T, M2, M3 at stations (both sides of a point load) and the max/min of each with its position
calculationDetailsobject—Node, member and DOF counts, and the global equilibrium residual in kN and kN·m
unitsobject—Units of every result field
warningsWarnings—Empty when nothing is flagged
⚠️ Pushes a warning, with reference Frame analysis, global equilibrium check, when the equilibrium residual exceeds 10⁻⁶ of the applied load — a sign of an ill-conditioned stiffness matrix. This is a solver check, not a code clause.
⚠️ Throws FrameAnalysisError 301–308 for an invalid model or an unstable structure; see the error table.
FN memberDemandEnvelope(result, memberId, options?) Public API Matrix analysis

Reduces a member's force diagrams to the design demands Mu⁺, Mu⁻, Vu and Nu, ready for rectBeamMomentCapacity and the shear functions. Takes plain numbers; it does not import the RC module.

Parameters
ParamTypeUnitRequired?Description
resultFrameResult—RequiredOutput of analyzeFrame
memberIdstring | number—RequiredMember to reduce
options.shearCriticalDistancenumbermmOptionalTake Vu only between this distance from each end, e.g. the effective depth d (default 0)
Example
TypeScript
const envelope = memberDemandEnvelope(result, "AB", {
  shearCriticalDistance: 540,  // mm, d
});
Returns
Result
{
  memberId: "AB",
  MuPositive: 70.3125,  // kN·m
  MuNegative: 125,      // kN·m, magnitude
  Vu: 103.4,           // kN
  Nu: 0,               // kN, tension positive
  VuRange: { from: 540, to: 4460 }  // mm
}
ℹ️ The sign of M3 depends on the member's local 2 axis. For a beam along X, local 2 is +Z, so sagging is positive and MuPositive is the span moment.
⚠️ Throws a plain Error if memberId is not in the result.

FN beam3dLocalStiffness(E, G, A, I22, I33, J, L) Public API Matrix analysis

The 12×12 local stiffness matrix of a prismatic beam, exactly as in the reference "Complete Beam Stiffness Matrix" (DOF order [U1, U2, U3, R1, R2, R3] at node i, then j). Returned in N and mm.

Parameters
ParamTypeUnitRequired?Description
EnumberMPaRequiredYoung's modulus
GnumberMPaRequiredShear modulus
Anumbermm²RequiredCross-section area
I22numbermm⁴RequiredUsed by the U3–R2 terms
I33numbermm⁴RequiredUsed by the U2–R3 terms
Jnumbermm⁴RequiredTorsion constant
LnumbermmRequiredMember length
Returns

A symmetric number[][]. Its nonzero terms are ±EA/L, ±GJ/L, 12EI/L³, ±6EI/L², 4EI/L and 2EI/L as laid out in the reference; with I22 = I33 it equals the reference's single-EI matrix.

ℹ️ The reference matrix measures the bending rotations R2 and R3 opposite to the right-hand rule, so it is free of force for rigid-body motion only with that sign. Use beam3dLocalStiffnessRightHanded when combining with right-handed quantities. analyzeFrame does this internally.
FN beam3dLocalStiffnessRightHanded(E, G, A, I22, I33, J, L) Public API Matrix analysis

The same element as beam3dLocalStiffness with every rotation following the right-hand rule: D·k·D, where D flips the sign of R2 and R3 at both nodes. This is the standard textbook matrix (for example F2,i = +6EI33/L²·R3,i).

Parameters and units are identical to beam3dLocalStiffness.

FN memberAxes(start, end, angle?) Public API Matrix analysis

Returns the member length and the ETABS-style local axes (see Axes & conventions) as the rows of a 3×3 direction-cosine matrix.

Parameters
ParamTypeUnitRequired?Description
start[number, number, number]mmRequiredStart node X, Y, Z
end[number, number, number]mmRequiredEnd node X, Y, Z
anglenumberradOptionalRotation of local 2 and 3 about local 1 (default 0)
Example
TypeScript
const { length, lambda } = memberAxes([0, 0, 0], [5000, 0, 0]);  // mm
// length = 5000
// lambda = [[1, 0, 0],    local 1 = +X
//           [0, 0, 1],    local 2 = +Z
//           [0, -1, 0]]   local 3 = −Y
⚠️ Throws FrameAnalysisError 301 if the two nodes coincide.

TYPE FrameResult Public API

Output of analyzeFrame; fields are described under analyzeFrame. A MemberDiagram holds { memberId, length, stations, extremes }; each station is { x, N, V2, V3, T, M2, M3 } and extremes maps each of those components to { max, min } with { value, x }.

FrameAnalysisError Codes

Thrown errors are instances of FrameAnalysisError (exported from @theerapat-s28/ts-structural-eng-tools/core, with the coded entries in FrameErrors). It mirrors RCDesignError and uses the 3XX range.

CodeNameMeaning
301ZERO_LENGTH_MEMBERA member's start and end nodes coincide.
302UNKNOWN_NODE_REFERENCEA member, restraint or load refers to a node or member id that is not in the model.
303DUPLICATE_IDNode ids, member ids or restrained node ids are not unique.
304STRUCTURE_UNSTABLEThe restrained structure is a mechanism (singular stiffness matrix): add supports or members.
305INVALID_SECTION_PROPERTIESE, G, A, I22, I33 or J is not a positive finite number.
306NO_RESTRAINTSNo DOF is fixed or sprung.
307INVALID_RELEASEThe end releases let the member move as a rigid body, for example axial or torsion released at both ends.
308LOAD_OUTSIDE_MEMBERA point load or a uniform load lies outside the member, or a uniform load's start is not before its end.
