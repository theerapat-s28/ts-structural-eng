Shell Element — Theory Notes

How a flat four-node shell element (membrane, plate bending and drilling rotation) gets its stiffness matrix, which formulations this library will use, and how the element fits into the existing frame solver.

Overview

The frame solver currently has one element: the 12-DOF prismatic beam. Slabs are null areas, which only distribute load, and walls are modelled as wide columns. A shell element adds stiffness to surfaces: shear walls and cores in their own plane, slabs and mats in bending, or both at once. These notes settle the theory and the formulations before any code is written, so the implementation has a reference to check against.

ℹ️ Implemented in 3.0.0 (flat four-node shells, membrane and thin plate, engine meshing, forces): shell areas are part of analyzeFrame (model.shells, shellForces; see the FEA reference). Thick plates and triangular elements are still to come (Roadmap Phase 5). Numbers on this page come from the library's tests unless marked prototype, which were checked with a throwaway prototype before the code existed. The basis is the finite element method, not a code provision FEM.

From beam to shell

Every element stiffness matrix comes from one formula. Write the strains inside the element in terms of the nodal displacements d as ε = B d, and the stresses as σ = D ε. The strain energy is then ½ dT(∫ BTD B dV) d, so

k = ∫V BT D B dV

The beam matrix in beam-3d-stiffness.ts is this integral worked out by hand. As an example, take the transverse displacement at the start node. Its cubic Hermite shape function, and the curvature it produces, are

N2(s) = 1 − 3s² + 2s³,   s = x / L     B = d²N2dx² = 12s − 6L²
k22 = ∫0L EI B² dx = EIL³ ∫01 (12s − 6)² ds = 12 EIL³

Numerical integration gives the same number. Use two Gauss points at s = ½(1 ∓ 1/√3), each with weight ½. At both points (12s − 6)² = 36/3 = 12, so the sum is ½·12 + ½·12 = 12, giving 12EI/L³ exactly. An n-point Gauss rule is exact for polynomials up to degree 2n − 1, and this integrand is only quadratic.

That is the whole trick for shells. The formula does not change, but the integral is evaluated at a few points instead of by hand.

Isoparametric quad

Each element is mapped from a parent square −1 ≤ ξ, η ≤ 1. The same bilinear functions interpolate both the geometry and the displacements, which is what "isoparametric" means:

Ni(ξ, η) = ¼ (1 + ξiξ)(1 + ηiη),    (ξi, ηi) = (−1, −1), (1, −1), (1, 1), (−1, 1)
x = Σi Ni xi,    y = Σi Ni yi      u = Σi Ni ui,    v = Σi Ni vi

Strains need derivatives in x and y, but the functions are written in ξ and η. The Jacobian converts between them:

J = ∂x/∂ξ∂y/∂ξ∂x/∂η∂y/∂η = Σi Ni,ξ xiNi,ξ yiNi,η xiNi,η yi     Ni,xNi,y = J−1 Ni,ξNi,η     dA = det J dξ dη

The stiffness integral then becomes a sum over four Gauss points:

k = ∫−11∫−11 BTD B det J dξ dη ≈ Σg=14 BT(ξg, ηg) D B(ξg, ηg) det J(ξg, ηg) ξg, ηg = ±1/√3, all weights 1

In code, the integration is the same short loop for every element on this page. Only the strain matrix changes:

TypeScript (sketch)
const g = 1 / Math.sqrt(3);
const gaussPoints = [[-g, -g], [g, -g], [g, g], [-g, g]];  // weights all 1

const k = zeros(nDof, nDof);
for (const [xi, eta] of gaussPoints) {
  const { B, detJ } = strainMatrix(xi, eta, corners);  // element-specific: membrane, DKQ, …
  addBtDB(k, B, D, detJ);                              // k += Bᵀ·D·B·det J
}
ℹ️ det J must be positive at every Gauss point. This requires the nodes to run counter-clockwise about local 3 and the quad to be convex. A reflex corner or a crossed ("bow-tie") quad makes det J ≤ 0 somewhere, so validation must reject it.
Membrane

The membrane carries in-plane (plane stress) behaviour: shear walls in their own plane and diaphragm action in slabs. Its local DOFs are u and v, plus θz (see the next section).

Why the plain bilinear quad is not enough

In pure bending, a beam's top and bottom edges curve (v ∝ x²) while its cross-sections stay plane (u ∝ xy). The bilinear quad can represent u = xy but not v = x², so its edges stay straight. To follow the bending it has to shear, and the spurious γxy stores shear energy that the real wall does not have. The element is therefore too stiff, and gets worse the longer it is relative to its depth. This is parasitic shear, the in-plane form of locking.

The bilinear Q4 is too stiff by a factor of ten. A wall modelled with one element through its depth would come out about ten times too stiff, so the plain Q4 is not an option. There are two standard cures:

  • Incompatible modes (Wilson; QM6 by Taylor, Beresford & Wilson 1976). Add four internal bubble modes, u += (1 − ξ²)α1 + (1 − η²)α2 and v += (1 − ξ²)α3 + (1 − η²)α4, then condense them out per element, k = kdd − kdα kαα−1 kαd. This is the same algebra as static-condensation.ts. It is exact in pure bending for rectangles. QM6 evaluates the bubble derivatives with the Jacobian at the element centre, so distorted elements still pass the patch test.
  • A drilling-rotation element. Its extra edge terms remove most of the parasitic shear, and it gives θz real stiffness.

Chosen: the drilling quad, because the shell needs θz stiffness anyway (next section). QM6 stays useful as an independent check in the tests.

Drilling rotation

Plane stress has no rotational DOF, but a shell node has six. The rotation about the shell normal, θz (the "drilling" rotation), needs stiffness of its own, and the frame depends on it:

ℹ️ A beam framing into a wall in the wall's plane (a coupling beam, a spandrel, a beam into a core) delivers its end moment through θz. Without drilling stiffness the wall cannot take that moment, so the beam end acts as a pin. A small fictitious spring on θz removes the singularity but not the pin, because the moment that spring can carry is negligible.
Allman-type edge interpolation

The drilling rotations add a quadratic bulge to each edge's normal displacement (Allman 1984; quad by Ibrahimbegovic, Taylor & Wilson 1990). Each mid-side function belongs to one edge, running from corner i to corner j counter-clockwise (N5 to N8 on edges 1→2, 2→3, 3→4, 4→1):

N5 = ½(1 − ξ²)(1 − η)   N6 = ½(1 + ξ)(1 − η²)   N7 = ½(1 − ξ²)(1 + η)   N8 = ½(1 − ξ)(1 − η²)
u = Σi Ni ui + Σk=58 Nk yj − yi8 (θj − θi)     v = Σi Ni vi + Σk=58 Nk xi − xj8 (θj − θi)

Here is where this comes from. The vector (yj − yi, xi − xj) is the edge length l times its outward unit normal. A counter-clockwise rotation θ makes the edge's normal displacement change at a rate −θ along the edge. A quadratic bump of height (l/8)(θj − θi) at mid-edge reproduces the difference between the two end slopes. The corner functions Ni stay bilinear.

Penalty on the rotation

Equal θ at every node adds nothing to u and v, so the edge terms on their own leave a zero-energy mode. The Hughes–Brezzi penalty fixes this by tying θ to the material's true in-plane rotation, ω = ½(v,x − u,y):

Π = ½ ∫ εT Dm ε dA + ½ γ t ∫ (θ − ω)² dA,    θ = Σi Ni θi
km = Σg ∈ 3×3 BmT Dm Bm det J + 4 γ t bγT bγ det J |ξ = η = 0 12×12 over [ui vi θi]; bγ is the row giving θ − ω

Bm now has 12 columns, because the edge terms put θ into u and v. γ = G (the shear modulus) is the usual choice. The two terms need different integration rules. This was settled while implementing the element (Roadmap 5.1):

ChoiceWhat goes wrongUsed

With these rules the 12×12 matrix has exactly three zero-energy modes, the in-plane rigid-body motions, for rectangles and distorted quads alike. It passes the MacNeal–Harder membrane patch test exactly when every boundary DOF, θ included, is prescribed; a free boundary θ lets the boundary edges bulge, so the patch is no longer held. On the straight cantilever it gives 0.0977 (regular mesh), 0.0931 (parallelogram) and 0.0829 (trapezoidal) against 0.1081.

ℹ️ The patch test cannot detect a wrong sign on the edge term. With the sign flipped, the prototype still passed the patch test exactly, but the cantilever's tip deflection dropped to 0.0031, about 30 times too stiff. Bending benchmarks are therefore part of the definition of done, not an optional extra.
Plate theory

The plate carries out-of-plane bending: slabs, mats, and walls under out-of-plane load. Its local DOFs are w, θx and θy, which are right-hand rotations about local x and y, as for members.

Kinematics. A point at height z above the mid-surface moves u = z βx, v = z βy, where βx and βy are the rotations of the normal in the x–z and y–z planes. In terms of the node rotations, βx = θy and βy = −θx.

κ = κxκyκxy = βx,xβy,yβx,y + βy,x    ε(z) = z κ     m = MxMyMxy = ∫ z σ dz = Db κ

Shear locking. The shear term's stiffness is κsGt, while bending's is Et³/12, so for an element of size h the ratio is of order (h/t)². In a thin plate, bilinear w and β cannot make γ = 0 throughout the element. The very stiff shear term then absorbs the deformation, and the plate barely deflects. Reduced (1-point) integration of the shear term cures the locking but introduces spurious "hourglass" modes. MITC4 cures both problems, and DKQ avoids them altogether.

DKQ plate

The discrete Kirchhoff quadrilateral (Batoz & Ben Tahar 1982) starts from independent rotations, as in Mindlin theory, so only first derivatives (C⁰ continuity) are needed. It then imposes the Kirchhoff condition at discrete points and along the edges instead of everywhere. Shear energy is never computed, so there is nothing to lock. The result is a 12-DOF element with w, θx and θy at each corner.

1
Interpolate the rotations of the normal with the 8-node serendipity functions: βx = Σi=18 Ni βxi, βy = Σ Ni βyi. Corner functions: Ni = ¼(1 + ξiξ)(1 + ηiη)(ξiξ + ηiη − 1). The mid-side N5…N8 are as in the drilling section.
2
Kirchhoff at the corners: βx = −w,x and βy = −w,y, i.e. βxi = θyi, βyi = −θxi for i = 1…4.
3
w is cubic along each edge in the edge coordinate s, from w and w,s at its two corners (Hermite).
4
Kirchhoff along each edge in the integral sense, ∫k (w,s + βs) ds = 0. Because βs is quadratic, this fixes the mid-side value at minus the cubic's mid-edge slope: βsk = −(3 / 2l)(wj − wi) + ¼(w,s i + w,s j).
5
The normal rotation is linear along each edge: βnk = ½(βni + βnj). Steps 4–5 eliminate the 8 mid-side parameters, leaving βx and βy as functions of the 12 corner DOFs only.

Uniform loads are lumped as ∫Ni q dA at each corner's w. Simply supported edges hold w, plus the rotation that w = 0 along the edge implies (θx on edges x = const, θy on edges y = const). On the 16 × 16 mesh the centre moment Mx, averaged over the four elements at the centre node, is 0.0480 qa² simply supported (reference 0.0479) and 0.0233 qa² clamped (0.0231). The deflection is identical for t/a = 0.01 and 0.3, as thin-plate theory requires. On the MacNeal–Harder strip the out-of-plane tip deflection is 0.4263, 0.4266 and 0.4261 on the regular, trapezoidal and parallelogram meshes (reference 0.4321), so distortion barely matters. The element has exactly three zero-energy modes (w = 1, w = x, w = y) for rectangles and distorted quads, and reproduces the MacNeal–Harder plate patch test exactly, moments included.

ℹ️ What DKQ does not provide. w is not defined inside the element (only along its edges), so pressure loads go to the w DOFs through ∫ Ni q dA. Transverse shear is not a strain quantity, so it is recovered from equilibrium, Qx = Mx,x + Mxy,y and Qy = Mxy,x + My,y, and is less accurate than the moments. There is no shear deformation, so thick plates come out too stiff.
Thick plates

There are two candidates for the later "thick" option:

  • MITC4 (Bathe & Dvorkin 1985). w, βx and βy are bilinear (Mindlin), and bending comes from the gradients of β with 2×2 points. The transverse shear is not taken straight from the displacement field. Instead, the covariant shear strains are sampled at the four edge midpoints and interpolated: γξz from A (0, 1) and C (0, −1), linear in η; γηz from B (−1, 0) and D (1, 0), linear in ξ. They are then transformed with J−1. MITC4 does not lock when thin, has no spurious modes and passes the patch test. It is widely used and well tested, but it is a separate formulation from DKQ.
  • DKMQ (Katili 1993). DKQ extended with transverse shear deformation, using the same H-function machinery. It reduces to DKQ when the plate is thin, so it reuses the most code.

Recommendation: choose after DKQ is in place. DKMQ is the shorter path from DKQ; MITC4 is the better-established element. Either way the input stays the same, apart from a plate-theory option, plateTheory: "thin" | "thick".

Local axes
  • Local 3 is the normal by the right-hand rule around nodeIds, as for null areas. For four nodes, Newell's vector area is exactly ½ d1 × d2 (diagonals d1 = x3 − x1, d2 = x4 − x2), so the null-area normal and the warped-quad mean-plane normal below are the same vector.
  • Non-horizontal element: local 2 is the projection of +Z onto the element plane (upward on a wall), and local 1 = 2 × 3 is horizontal.
  • Horizontal element: local 1 = +X and local 2 = 3 × 1 (so local 2 = +Y when local 3 = +Z).
  • An optional angle rotates local 1 and 2 about local 3, as for members. The formulation's x, y are local 1, 2, so results come out directly in local axes.
Transformation

As for members, kglobal = TT klocal T, with T block-diagonal in the 3×3 direction cosines λ (rows = local 1, 2, 3). A quad has 8 blocks instead of a member's 4. It is cheaper to transform block by block, kab ← λT kab λ for each 3×3 block, than to form the 24×24 T.

Warped quads

Four nodes are rarely exactly coplanar. Project them onto the mean plane through their centroid, with unit normal n ∥ d1 × d2. The nodes then sit alternately a distance h above and below that plane:

h = ¼ (x1 − x2 + x3 − x4) · n,    hi = +h, −h, +h, −h

Build the flat element on the projected nodes. Then connect each real node to its projection with a rigid link, uproj = u + hi (n × θ). With W the block matrix of these links, k = WT kflat W. In local components the link adds −hi·r2 to u1 and +hi·r1 to u2, so each corner's 6×6 transformation is λ on translations and rotations plus those two terms; the global matrix is assembled block by block from them. Member end offsets (Roadmap 2.1) need the same rigid-link algebra. Validation should warn above one warping ratio and reject above a larger one, with the thresholds set from the benchmarks.

The links are what keep a warped element free of force under rigid-body motion: without them a rigid rotation of a warped element is resisted. On the MacNeal–Harder twisted beam, where every element is warped, the element gives 5.410·10⁻³ and 1.7575·10⁻³ (references 5.424·10⁻³ and 1.754·10⁻³) for t = 0.32, and 5.282·10⁻³ and 1.300·10⁻³ (5.256·10⁻³ and 1.294·10⁻³) for t = 0.0032 with P = 10⁻⁶ (Roadmap 5.3 tests).

Stiffness modifiers

Cracked-section stiffness per ACI 318-19 Table 6.6.3.1.1(a) (walls 0.70 Ig uncracked or 0.35 Ig cracked; flat plates and flat slabs 0.25 Ig) is applied by modifying Dm and Db along local 1 and 2, ETABS-style: f11, f22, f12 for membrane and m11, m22, m12 for bending. Each matrix becomes S·D·S with S = diag(√f11, √f22, √f12): D11, D22 and D33 scale by their own modifier and the coupling D12 by √(f11f22), so D stays symmetric and positive definite and equal modifiers scale it uniformly. The drilling penalty keeps the unmodified G. The modifiers are linear, so superposition is unaffected.

Loads

Shells have no fixed-end forces. A distributed load becomes equivalent nodal loads through the same Gauss loop, fi = ∫ Ni p dA.

  • Uniform pressure q in kN/m², along local 3 or a global axis, as for AreaLoad. In N and mm, 1 kN/m² = 10⁻³ N/mm². On a rectangle, each corner takes qA/4.
  • Self-weight is unit weight × t per unit area along −Z, resolved into local components: the in-plane part goes to u, v (membrane) and the normal part to w (plate).
  • DKQ has no interior w field, so its load vector uses the bilinear Ni on the w DOFs and no nodal moments. The prototype converged to the Timoshenko values with this choice.

All of these are linear in the load, so each load case's vector goes through the existing per-case solve and combinations still superpose. Shell loads use AreaLoad: areaId names either a null area or a shell area, in one id namespace, and the kind of area decides how the load reaches the structure. Loads on null areas still go to the edge members through distributeAreaLoads, which ignores loads on shells.

  • Per-element values: return corner values per element. Averaging across elements at a node is a display choice and belongs in the front end.
  • Superposition: all of these are linear in the displacements, so they are computed from each raw state and rounded only in present-state.ts, as for members.
  • Checks (Roadmap 5.5 tests): on a cantilever strip M11 is linear and V13 constant exactly; on a 16 × 16 square plate (ν = 0.3) the centre moment is 0.0480 qa² simply supported (0.0479) and 0.0233 qa² clamped (0.0231), and the clamped edge moment −0.0512 qa² (−0.0513). The recovered edge shear reaches about 80 % (simply supported) and 90 % (clamped) of Timoshenko's peak, so shears are the coarsest output.
  • Design: design quantities (for example Wood–Armer slab moments, or wall pier and spandrel forces from section cuts) belong in rc/ or a later helper, not in the element.
Meshing mesh/

The engine meshes (Roadmap 5.6). The user models a shell area by its 4 corner nodes, as for a null area, with mesh: { maxSize } or { divisions }; the engine generates the elements. One element per wall or slab panel is never adequate (see the membrane table), so meshing is the normal case.

1
Edges cut at model nodes. Each area edge is cut into segments at the model nodes lying on it (hard points: a column, a beam end, the corner of a neighbouring area). A segment is identified by its two end nodes, so two areas sharing an edge, or meeting along part of one (a slab edge on two wall panels, a T-junction), share the same segments.
2
Division counts. Every segment gets a count c ≥ 1, at least ⌈length / maxSize⌉ for an area with maxSize. Each area needs its opposite edges to add up to the same count (and at least divisions): Σc over edge 0 = Σc over edge 2, and edge 1 = edge 3. The counts are raised until every area balances, each extra division going to the segment whose elements are longest. This generalises the planned "chord" rule (shared edges and opposite edges tied together) to edges made of several segments. If no balance is reached within a few passes per area, the areas get error 329.
3
Nodes. Segment nodes are evenly spaced and named "<a>~<b>:<k>" from its end node a to b. Inside each area, nodes come from transfinite (Coons) interpolation of its four edges, using each edge's own spacing, and are named "<areaId>:<i>,<j>"; with even spacing this is exactly the bilinear map of the area, so a planar area stays planar.
4
Elements and checks. Elements "<areaId>:<i>,<j>" keep the area's orientation and properties; an area that stays 1 × 1 keeps its own id. Every generated element must be a valid quadrilateral and every generated id new, otherwise 329.
5
Members on meshed edges. A member with generated nodes inside it is split there internally, so it shares them with the shells. Releases stay at its real ends; its member loads are resolved over its whole length and then cut at the pieces; its end forces come from the first and last piece, and its diagram is stitched from the pieces' own diagrams (both sides reported where the shells feed load in). Results stay under the member's id, so envelopes and design demands are unchanged. A test against the same beams split by hand gives identical displacements, end forces and diagram extremes.
6
Supports and warnings. lineRestraints fix DOFs at every node on a segment between two nodes, generated nodes included, so a wall base can be fixed along its length. A member node lying inside an area but not on its mesh is reported as a warning, because it is not connected to the shell.

Triangular areas need a triangular element (DKT with an Allman triangle) or a split of each triangle into quads. Openings are handled by dividing the area around them; the segment counts keep the result conforming. Both come in later phases.

Engine integration

The analysis stays linear, so the overall design carries over unchanged: factorise once, solve each case into a raw state, superpose combinations, and round only on presentation. What changes is everything that assumes "an element has 2 nodes and 12 DOFs".

Implementation order

The phases match Phase 5 of ROADMAP.md. Each ends with lint, tests and build passing.

5.0
Generic element assembly. Refactor only: assembly, RCM adjacency, profile and auto-restraint take elements with any number of nodes. Results of existing models are identical.
5.1
Membrane quad with drilling. Bilinear Q4 first (patch test), then the Allman edge terms and the penalty. Benchmarks: cantilever, Cook's membrane, a sign check.
5.2
DKQ plate. Rigid-body modes, plate patch test, Timoshenko plates, cantilever strip.
5.3
Flat shell. Local axes, 24×24 assembly, behaviour switch, modifiers, transformation, warping links.
5.4
Shells in the model. Types, validation (326–328), assembly with the members, AreaLoad and self-weight on shells. Benchmarks: Scordelis–Lo, pinched cylinder, beam into wall, wall vs wide column.
5.5
Shell results and first release. Corner forces, moments, shears and stresses; combinations and envelope; the FEA doc page, README and CHANGELOG.
5.6
Engine meshing. Structured quads, the chord rule, hard points (5.6a); members split along meshed edges (5.6b).
5.7
Thick plates. DKMQ or MITC4 behind plateTheory: "thick".
5.8
Triangles and openings. DKT with an Allman triangle; triangular areas in the mesher.
