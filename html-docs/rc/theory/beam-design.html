RC Beam Design — Theory Notes

The ACI 318-19 basis of the rc module: the flexural strength of rectangular sections by the equivalent rectangular stress block, the one-way shear strength and stirrup requirement, the bar layout, and the section properties used for analysis, with worked examples.

⚠️ A calculation aid, not a substitute for engineering judgement. Results must be checked and accepted by the qualified engineer responsible for the design. Scope, assumptions and limitations →
Overview

The rc module checks a rectangular reinforced-concrete beam section: its design moment strength φMn, its design shear strength φVc + φVs, whether it needs stirrups, how its bars fit into layers, and the stiffness to give it in a frame analysis. All formulas are the SI forms of ACI 318-19. Units are N and mm inside each calculation; moments are returned in kN·m and forces in kN.

ℹ️ Every number on this page comes from running the shown inputs through the library, and each worked example was checked by hand. The formulas are read from src/rc/ and the constants from src/core/constants/rc.constant.ts.

Design assumptions

The flexural strength follows the design assumptions of ACI 318-19, 22.2:

  • Plane sections. Strain varies linearly with depth (22.2.1.2).
  • Concrete crushing strain εcu = 0.003 at the extreme compression fibre (22.2.2.1; CONCRETE_ULTIMATE_STRAIN).
  • No tensile strength of concrete in flexure (22.2.2.2).
  • Equivalent rectangular stress block of 0.85f′c over a depth a = β1c (22.2.2.4).
  • Elastic–perfectly plastic steel: fs = Esεs up to fy, then fy (20.2.2.1, 20.2.2.2).

Depths d and d′ are measured from the extreme compression fibre (the top face of the concrete for a sagging moment). d′ may be negative, which places compression steel above that face; strengthening uses this for a top plate.

Stress block factor β1 general.ts
β1 = 0.85 for f′c ≤ 28 MPa,   β1 = 0.85 − 0.05 (f′c − 28)/7 ≥ 0.65 for f′c > 28 MPa ACI 318-19 Table 22.2.2.4.3
Singly reinforced section rc-beam-design.ts

With the tension steel assumed to yield, horizontal equilibrium C = T gives the depth of the stress block:

0.85 f′c b a = As fy  ⇒   a = As fy0.85 f′c b,   c = a / β1

The strain in the tension steel follows from the linear strain profile, and the assumption is checked (below):

εt = εcu d − cc

Taking moments about the centroid of the stress block:

Mn = As fy ( d − a/2 ),   φMn = 0.9 Mn
Worked example
TypeScript
const r = rectBeamMomentCapacity({
  Es: 200000, // MPa
  fy: 400,    // MPa
  fc_: 28,    // MPa
  b: 300,     // mm
  h: 500,     // mm
  d: 440,     // mm
  As: 1520,   // mm²
});
// r.phiMn = 217.47 kN·m
// r.calculationDetails = { c: 100.18, a: 85.15, beta1: 0.85, d: 440, As: 1520, ro: 0.011515 }

By hand: a = 1520 × 400 / (0.85 × 28 × 300) = 85.15 mm, c = 85.15 / 0.85 = 100.18 mm, εt = 0.003 × (440 − 100.18)/100.18 = 0.0102 ≥ 0.002 + 0.003, so the section is tension-controlled. Mn = 1520 × 400 × (440 − 42.57) = 241.6 kN·m and φMn = 217.47 kN·m.

Doubly reinforced section

The compression steel A′s at depth d′ has the strain ε′s = εcu(c − d′)/c, positive in compression. The engine first assumes it stays elastic, with the tension steel yielding:

0.85 f′c b β1 c + A′s Es εcu c − d′c = As fy

Multiplying by c gives a quadratic in c:

(0.85 f′c b β1) c² + (εcu A′s Es − As fy) c − εcu A′s Es d′ = 0

The positive root for which |Esε′s| ≤ fy is taken. (With d′ < 0 both roots can be positive, so the root is chosen by the elastic condition rather than by size.) If no root keeps the compression steel elastic, it has yielded, and equilibrium is solved again with f′s = ±fy:

c = (As ∓ A′s) fy0.85 f′c b β1upper sign: yields in compression; lower sign: yields in tension (steel below the neutral axis)

The nominal strength, taking moments about the tension steel:

Mn = 0.85 f′c b a ( d − a/2 ) + A′s f′s ( d − d′ ),   a = β1c
  • Compression steel below the neutral axis (d′ > c) is in tension, so f′s < 0 and it reduces Mn. This is a valid section, so the engine returns the result with a warning citing ACI318-19, 22.2.1.2 rather than throwing.
  • c ≤ 0 means the compression steel alone outweighs the tension steel: no equilibrium exists with the tension steel yielding, and RCDesignError 102 is thrown.
Worked example
TypeScript
const r = rectBeamMomentCapacity({
  Es: 200000, fy: 400, fc_: 28, // MPa
  b: 300, h: 500, d: 440, d_: 60,  // mm
  As: 2280, As_: 628,              // mm²
});
// r.phiMn = 317.94 kN·m
// c: 119.39, a: 101.48, fs_: 298.46 (MPa, elastic), ro: 0.017273, ro_: 0.004758

By hand: f′s = 200000 × 0.003 × (119.39 − 60)/119.39 = 298.46 MPa < 400 MPa, so the compression steel is elastic. Mn = 0.85 × 28 × 300 × 101.48 × (440 − 50.74) + 628 × 298.46 × (440 − 60) = 282.0 + 71.2 = 353.3 kN·m, and φMn = 317.94 kN·m.

Tension control and φ

ACI 318-19 Table 21.2.2 classifies a section by the net tensile strain εt in the extreme tension steel. With εty = fy/Es:

εt ≥ εty + 0.003  ⇒   tension-controlled, φ = 0.90

The engine computes φMn only for tension-controlled sections. A section below that limit is in the transition or compression-controlled zone, where both the assumption that the tension steel yields and φ = 0.90 fail, so rectBeamMomentCapacity throws RCDesignError 102 instead of returning a value. The tension-control limit is stricter than the beam limit εt ≥ 0.004 of 9.3.3.1, so a returned result satisfies both.

⚠️ Throws RCDesignError 102 when εt < εty + 0.003. Increase the depth or the concrete strength, or add compression steel; do not reduce As just to pass the check without checking strength.
Minimum flexural reinforcement
As,min = max( 0.25√f′cfy b d,  1.4fy b d )ACI 318-19, 9.6.1.2
⚠️ Pushes a warning when As < As,min — ACI318-19, 9.6.1.2. A second warning is pushed when fy > 550 MPa (see the points for review on its citation).
Concrete shear strength Vc
Vc = 0.17 λ √f′c bw d,   √f′c ≤ 8.3 MPa,   φ = 0.75 ACI 318-19 Table 22.5.5.1(a), 22.5.3.1, 21.2.1

λ is the lightweight-concrete factor (1.0 by default). When √f′c exceeds 8.3 MPa it is capped, and a warning cites ACI318-19, 22.5.3.1: the cap may be lifted only when minimum shear reinforcement is provided.

TypeScript
concreteShearCapacity({ fc_: 28, bw: 300, d: 440 }); // MPa, mm, mm
// { phiVc: 89.06, calculationDetails: { Vc: 118.74, lambda: 1 }, unit: "kN" }

By hand: Vc = 0.17 × 1.0 × √28 × 300 × 440 = 118.74 kN, φVc = 0.75 × 118.74 = 89.06 kN.

Stirrup shear strength Vs

For vertical stirrups of area Av (all legs) at spacing s:

Vs = Av fyt ds,   Vs ≤ 0.66 √f′c bw d ACI 318-19, 22.5.1.2 (the cap that prevents web crushing)
TypeScript
stirrupShearCapacity({ fc_: 28, bw: 300, d: 440, Av: 157, fyt: 400, s: 150 });
// { phiVs: 138.16, calculationDetails: { Vs: 184.21, maxVs: 461 }, unit: "kN" }

By hand: Vs = 157 × 400 × 440 / 150 = 184.21 kN ≤ 0.66 × √28 × 300 × 440 = 461.0 kN; φVs = 138.16 kN.

⚠️ Throws RCDesignError 105 when Vs exceeds 0.66√f′c bw d: the section is too small for shear, and more stirrups cannot fix it.
Stirrup requirement

checkStirrupRequirement classifies a section under a factored shear Vu:

DemandRequired Av/sMaximum spacing
Vu ≤ 0.5φVcNone (required: false)—
0.5φVc < Vu ≤ φVc(Av/s)min (minimumOnly: true)min(d/2, 600 mm)
Vu > φVcmax((Av/s)min, Vs,req / (fyt d))min(d/2, 600) if Vs,req ≤ 0.33√f′c bw d, else min(d/4, 300)
(Av/s)min = max( 0.062√f′c bw/fyt,  0.35 bw/fyt ),   Vs,req = Vu/φ − Vc ACI 318-19, 9.6.3.3; 9.6.3.1; 9.7.6.2.2

When Av and s are given, they are checked against the required ratio and the maximum spacing.

TypeScript
checkStirrupRequirement({ fc_: 28, bw: 300, d: 440, Vu: 200, fyt: 400, Av: 157, s: 200 });
// required: true, minimumOnly: false
// calculationDetails: { phiVc: 89.06, halfPhiVc: 44.53, requiredAvOverS: 0.8405, maxSpacing: 220 }
// warnings: [{ reference: "ACI318-19, 9.6.3.1", message: "Provided Av/s (0.785 mm2/mm) < required Av/s (0.8405 mm2/mm)." }]

By hand: Vs,req = 200/0.75 − 118.74 = 147.93 kN, so Av/s = 147 926 / (400 × 440) = 0.8405 mm²/mm, above the minimum of 0.2625. Vs,req is below 0.33√28 × 300 × 440 = 230.5 kN, so smax = min(220, 600) = 220 mm. The provided 157/200 = 0.785 mm²/mm is short, hence the warning.

⚠️ Pushes a warning when the provided Av/s is below the requirement — ACI318-19, 9.6.3.1 — and when s exceeds the maximum spacing — ACI318-19, 9.7.6.2.2.
⚠️ Throws RCDesignError 105 when Vs,req exceeds 0.66√f′c bw d.
Bar layout rc-bar-layout.ts

rectBeamBarLayout fits a group of equal bars of diameter db into layers and returns the effective depths. The clear spacing within a layer and the pitch between layers are

sclear = max( 25 mm, db, 4/3 · dagg ),   layer pitch = db + 25 mm ACI 318-19, 25.2.1 and 25.2.2
nlayer = ⌊ ( b − 2(cc + ds) + sclear ) / ( db + sclear ) ⌋ cc: clear cover to the stirrup, ds: stirrup diameter
  • The number of layers is ⌈n / nlayer⌉, and the bars are shared as evenly as possible between the layers, the extra bars going to the layers nearest the face.
  • The first layer's centre is at cc + ds + db/2 from the face; d = h − (centroid of the bottom group) and d′ = centroid of the top group.
  • Defaults: cover 40 mm (Table 20.6.1.3.1, cast-in-place beams not exposed to weather or in contact with ground), stirrup 10 mm, aggregate 20 mm.
  • A section that cannot hold one bar throws RCDesignError 103; top and bottom layers that overlap throw 104.
TypeScript
rectBeamBarLayout({ b: 300, h: 500, // mm
  bottomBars: { count: 5, diameter: 20 }, topBars: { count: 2, diameter: 16 } });
// d: 422, d_: 58, bottom: { numberOfLayers: 2, barsPerLayer: [3, 2], As: 1570.8 }, top: { numberOfLayers: 1, ... }

By hand: sclear = max(25, 20, 26.7) = 26.7 mm, nlayer = ⌊(200 + 26.7)/46.7⌋ = 4, so 5 bars need 2 layers, shared [3, 2]. The layers sit at 60 and 105 mm from the bottom face, the centroid at (3 × 60 + 2 × 105)/5 = 78 mm, so d = 422 mm.

Section properties for analysis rc-section-properties.ts

rectBeamToSectionProperties gives a frame member the stiffness of a rectangular RC section. Local 2 runs along the depth h and local 3 along the width b:

E = 4700√f′c,  G = E / (2(1 + ν)),  A = b h,  I33 = m · b h³/12,  I22 = m · h b³/12
J = a t³ [ 1/3 − 0.21 (t/a) (1 − t⁴/(12a⁴)) ]a = longer side, t = shorter side; Saint-Venant torsion of a solid rectangle

m is the cracked-section modifier of ACI 318-19 Table 6.6.3.1.1(a): 0.35 for beams (default), 0.70 for columns, 1.0 for gross properties (which adds a warning citing ACI318-19, 6.6.3.1.1). It applies to the bending inertias only; A and J are gross, and ν = 0.2. The unit weight for self-weight is 24 kN/m³ by default, a common design value and not an ACI one.

TypeScript
rectBeamToSectionProperties({ fc_: 28, b: 300, h: 500 });
// E: 24870.06 MPa, G: 10362.53 MPa, A: 150000 mm², I33: 1.09375e9 mm⁴, I22: 3.9375e8 mm⁴,
// J: 2.81737e9 mm⁴, unitWeight: 24 kN/m³
ℹ️ ACI 318-19 Ec = 4700√f′c applies to normalweight concrete (19.2.2.1(b)). For lightweight concrete or a measured modulus, build SectionProperties directly.

Limitations
  • Rectangular sections only. No T- or L-beams, so the flange of a beam cast with a slab is ignored (conservative for sagging strength, but a narrow web can fail the tension-control check that the flanged section would pass).
  • Tension-controlled flexure only, with φ = 0.90. No transition-zone φ, no axial load, no columns.
  • One layer centroid. The tension steel is lumped at its centroid d. The strain is not checked at each layer, so the extreme layer is slightly more strained than εt at d.
  • Vertical stirrups only; no inclined stirrups or bent-up bars, no torsion reinforcement, no shear friction.
  • Section checks only. No deflection (9.5, 24.2), crack control (24.3), development length and splices (25.4, 25.5), bar cut-off, or seismic detailing (Chapter 18).
  • SI only: the coefficients are the SI forms of the ACI expressions. psiToMpa converts strengths but there is no US-customary path.
Points for review
  • Choice of the Vc expression. ACI 318-19 Table 22.5.5.1 allows expression (a), 0.17λ√f′c bw d, only when Av ≥ Av,min. For a member with less than the minimum shear reinforcement it requires expression (c), 0.66 λs λ ρw1/3 √f′c bw d, which has the size-effect factor λs and can be markedly lower for deep, lightly reinforced members. The engine always uses (a). This matters for the classification Vu ≤ 0.5φVc (no stirrups needed) and for members without stirrups.
  • Displaced concrete. The compression steel force is A′s f′s, without deducting the concrete it displaces (A′s · 0.85f′c). This is a common simplification and slightly overestimates C.
  • Clause citations to confirm. The fy > 550 MPa warning cites 9.6.1.2, but the limit on fy is set by 20.2.2.4 (Table 20.2.2.4(a)). The Vs formula is cited in the code as 22.5.10.5.3, which appears to be the ACI 318-14 number; ACI 318-19 places it in 22.5.8.5.3. Both should be checked against the code text and corrected.
  • Rounded intermediates. checkStirrupRequirement uses Vc and φVc as rounded to 0.01 kN by concreteShearCapacity. The effect is below 0.01 kN, but it departs from the rule that intermediate values stay unrounded.
  • Unit string. rectBeamMomentCapacity returns unit: "kN-m", while other functions use "kN·m". Front ends that compare unit strings should allow for both.
  • Bar sharing between layers. The layout shares bars evenly between layers ([3, 2] for 5 bars that fit 4 to a layer) instead of filling the first layer (4, 1). This gives a smaller d than the fullest packing, which is conservative.
