# TS-init-project

A minimal TypeScript starter project for building small functions and libraries that can be reused across TypeScript frameworks (Express, Angular, etc.). It includes TypeScript, ts-node for development, build script to emit JS and type declarations, and a `.gitignore`.

## Requirements

- Node.js (v14+ recommended)
- pnpm (project uses pnpm; npm or yarn may work but commands below assume pnpm)

## Project layout

- `src/` — TypeScript source files (entrypoint: `src/index.ts`)
- `tsconfig.json` — TypeScript compiler options
- `dist/` — compiled JavaScript and `.d.ts` declarations (generated by `pnpm run build`)
- `package.json` — scripts and dependencies

## Scripts

- Install dependencies

```zsh
pnpm install
```

- Run in development (execute TypeScript directly with `ts-node`)

```zsh
pnpm run dev
```

This runs `ts-node src/index.ts` and is convenient for quick iteration.

- Build (compile TypeScript -> JavaScript and generate declaration files)

```zsh
pnpm run build
```

After building, the compiled output will be in `dist/` (for example `dist/index.js` and `dist/index.d.ts`).

- Run the compiled output with Node

```zsh
node dist/index.js
```

## Publishing / Reuse

If you plan to publish this as a package for consumption by other TypeScript projects, the `package.json` now points:

- `main`: `dist/index.js`
- `types`: `dist/index.d.ts`

Ensure you run `pnpm run build` before publishing so the compiled JS and declaration files are included.

## Recommendations

- Export named functions in `src/` so they are easy to import in other projects.
- Add tests (Jest/Vitest) and CI if this becomes a public/shared library.
- Optionally add ESLint/Prettier for consistent style.
